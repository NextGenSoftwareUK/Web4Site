# OASIS WEB4 — The Unification Layer

**One Avatar. One Karma Score. One Wallet. Everything Connected.**

OASIS WEB4 is the universal unification layer of the OASIS Omniverse — a technology that sits above all existing Web2 and Web3 protocols and abstracts them into a single, coherent identity, data, karma and asset system across 40+ providers.

## What is WEB4?

WEB4 solves the fragmentation problem of the modern internet. Today, you have dozens of identities, wallets, profiles and data stores spread across incompatible platforms. WEB4 unifies them:

| Without WEB4 | With WEB4 |
|---|---|
| Separate identity per platform | One OASIS universal avatar |
| Separate wallet per chain | One wallet, every chain |
| Karma/points per app | One karma score, every app |
| Data locked per provider | One data layer, 40+ providers |
| NFTs per blockchain | NFTs portable across all chains |

## Provider Support (40+)

WEB4 includes adapters for: MongoDB, SQL Server, PostgreSQL, Holochain, Ethereum, Solana, Polygon, Arbitrum, IPFS, Filecoin, Arweave, ThreeFold, ActivityPub, Nostr, AT Protocol, and many more — all behind a single unified OASIS API.

## Core Primitives

- **OASIS Avatar** — universal identity with SSO across every connected app
- **OASIS Karma** — global karma score earned across all platforms and games
- **OASIS Wallet** — unified multi-chain wallet
- **OASIS NFTs** — cross-chain NFTs usable in every connected world
- **OASIS DNA** — encrypted personal data vault, user-owned and portable
