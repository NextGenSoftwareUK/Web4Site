2 · Read and edit the request

Write a SQL-like CQL query

Use SELECT * for full rows, SELECT Id, Name, Version for selected columns on one database, or SELECT COUNT(*), ANY(*), MIN(Version), MAX(Version), SUM(Version), or AVG(Version) for one database. List multiple providers for a federated row query. Use ParentHolonId with a quoted GUID to filter by direct parent. Use EXISTS CHILD or EXISTS DESCENDANT to filter by related records. TIMEOUT sets the row query budget in milliseconds (up to 30,000). Filter unsigned 64-bit metadata with metadata.Sequence AS UINT64 >= 9007199254740993. Filter Boolean metadata with metadata.someFlag AS BOOLEAN = TRUE. Test nested metadata with metadata.location.city IS PRESENT or metadata.location.zip IS NULL.

Example with child and descendant filters 
SELECT Id, Name, Version FROM MongoDBOASIS
WHERE IsActive = TRUE
  AND EXISTS CHILD (Version >= 2)
  AND EXISTS DESCENDANT (IsActive = TRUE)
ORDER BY Name LIMIT 5

filters are combined with AND. anyOf adds an OR group. In selects an array of exact values. metadataPath selects a metadata key. skip and take page the results. This editor accepts JSON, not executable C#, SQL or Cypher. The server checks permissions, bounds and provider capabilities.
